28 Etiquetas HTML5

En esta página se presentan 28 etiquetas de HTML5, incluyendo su definición, utilidad, ejemplo y resultado.

1. <blockquote>

Definición

<blockquote> es una etiqueta de HTML utilizada para representar una cita extensa tomada de otra fuente.

¿Para qué sirve?

Sirve para identificar semánticamente una cita larga y diferenciarla del contenido escrito por el autor de la página.

Ejemplo

La educación es una herramienta fundamental para adquirir nuevos conocimientos.

Resultado

El navegador mostrará el texto de la cita separado visualmente del texto normal.

2. <picture>

Definición

<picture> es un elemento HTML que permite proporcionar diferentes versiones de una imagen para que el navegador pueda seleccionar la más adecuada.

¿Para qué sirve?

Se utiliza principalmente para mostrar imágenes diferentes dependiendo del tamaño o características de la pantalla.

Ejemplo

Resultado

El navegador mostrará una imagen y podrá seleccionar una versión diferente dependiendo del tamaño disponible.

3. <track>

Definición

<track> es una etiqueta utilizada dentro de <video> y <audio> para agregar pistas de texto sincronizadas con contenido multimedia.

¿Para qué sirve?

Puede utilizarse para subtítulos, traducciones, descripciones y otros tipos de información relacionada con un archivo multimedia.

Ejemplo

Resultado

Se mostrará un reproductor de video. Si existen los archivos correspondientes, se podrán activar los subtítulos en español.

4. <iframe>

Definición

<iframe> significa "Inline Frame". Permite insertar otro documento HTML dentro de la página actual.

¿Para qué sirve?

Se utiliza para incorporar contenido externo como páginas web, mapas, videos u otros documentos.

Ejemplo

Resultado

Aparecerá una ventana dentro de la página que contiene el contenido del sitio indicado.

5. <wbr>

Definición

<wbr> significa "Word Break Opportunity". Indica un lugar donde el navegador puede realizar un salto de línea.

¿Para qué sirve?

Sirve para evitar problemas de visualización cuando existen palabras o cadenas extremadamente largas.

Ejemplo

EsteEsUnTextoMuyLargo QuePuedeDividirse EnDiferentesPartes.

Resultado

El navegador podrá realizar un salto de línea en los puntos indicados cuando sea necesario.

6. <kbd>

Definición

<kbd> representa una entrada que normalmente realiza el usuario mediante un teclado u otro dispositivo de entrada.

¿Para qué sirve?

Se utiliza principalmente para mostrar teclas, combinaciones de teclas y comandos.

Ejemplo

Para guardar un archivo presiona Ctrl + S.

Resultado

Se mostrará la combinación de teclas que debe presionar el usuario.

7. <samp>

Definición

<samp> representa una salida o resultado producido por un programa informático.

¿Para qué sirve?

Sirve para identificar dentro de un documento el texto que representa una respuesta generada por un programa.

Ejemplo

Resultado: Archivo guardado correctamente.

Resultado

El mensaje se identifica como una salida producida por un programa.

8. <time>

Definición

<time> representa una fecha, una hora o un periodo específico de tiempo.

¿Para qué sirve?

Permite identificar información temporal de manera semántica para los navegadores y otros programas.

Ejemplo

La clase comienza a las 8:00 AM.

La fecha del evento es 24 de septiembre de 2026.

Resultado

El usuario podrá ver la fecha y hora normalmente, mientras que el atributo datetime proporciona información estructurada.

9. <data>

Definición

<data> permite asociar un contenido visible para el usuario con un valor que puede ser interpretado por una máquina.

¿Para qué sirve?

Se utiliza cuando queremos mostrar información legible para las personas y proporcionar también un valor estructurado para los programas.

Ejemplo

Producto: Computadora portátil

Resultado

El usuario verá "Computadora portátil", mientras que el valor asociado será "001".

10. <q>

Definición

<q> representa una cita corta que forma parte del contenido de un párrafo.

¿Para qué sirve?

Se utiliza para marcar citas breves que aparecen directamente dentro de una oración.

Ejemplo

Mi profesor siempre dice: La práctica ayuda a mejorar.

Resultado

El navegador mostrará la frase como una cita corta.

11. <cite>

Definición

<cite> se utiliza para identificar el título de una obra creativa, como un libro, película, canción o artículo.

¿Para qué sirve?

Sirve para indicar claramente que un texto corresponde al título de una obra.

Ejemplo

Una obra literaria famosa es Don Quijote de la Mancha.

Resultado

El título de la obra queda identificado semánticamente.

12. <sup>

Definición

<sup> representa un texto que debe mostrarse como superíndice.

¿Para qué sirve?

Se utiliza frecuentemente para representar potencias, exponentes, referencias y notas.

Ejemplo

Dos elevado a tres: 23 = 8

Resultado

El número 3 aparecerá elevado respecto al número 2.

13. <small>

Definición

<small> representa información secundaria, como notas, aclaraciones o información complementaria.

¿Para qué sirve?

Se utiliza para diferenciar información secundaria del contenido principal.

Ejemplo

Precio: $500 IVA incluido.

Resultado

La información secundaria aparecerá con un tamaño de texto menor en la presentación predeterminada.

14. <abbr>

Definición

<abbr> representa una abreviatura o acrónimo. Puede utilizar el atributo title para proporcionar el significado completo.

¿Para qué sirve?

Ayuda a identificar abreviaturas y proporciona información adicional sobre su significado.

Ejemplo

Estoy aprendiendo HTML.

Resultado

Se mostrará "HTML". Al colocar el cursor sobre la abreviatura puede aparecer su significado.

15. <dfn>

Definición

<dfn> identifica el término que está siendo definido dentro de un texto.

¿Para qué sirve?

Se utiliza para marcar un concepto o término cuando se está proporcionando su definición.

Ejemplo

HTML es un lenguaje de marcado utilizado para estructurar contenido en páginas web.

Resultado

El término HTML queda identificado como el concepto que está siendo definido.

16. <ins>

Definición

<ins> representa contenido que ha sido insertado o agregado a un documento.

¿Para qué sirve?

Se utiliza para identificar información nueva que fue agregada posteriormente a un texto.

Ejemplo

Precio actualizado: $400

Resultado

El contenido agregado se mostrará identificado como una inserción.

17. <del>

Definición

<del> representa contenido que ha sido eliminado de un documento.

¿Para qué sirve?

Se utiliza para mostrar información que anteriormente formaba parte del documento pero que posteriormente fue eliminada.

Ejemplo

Precio anterior: $500

Resultado

El precio anterior aparecerá normalmente tachado en la presentación predeterminada del navegador.

18. <progress>

Definición

<progress> representa el progreso de una tarea que se encuentra en proceso de realización.

¿Para qué sirve?

Puede utilizarse para mostrar el avance de una descarga, instalación, carga de información u otra tarea.

Ejemplo

Progreso de la descarga:

70%

70% completado.

Resultado

El navegador mostrará una barra de progreso indicando que la tarea se encuentra al 70%.

19. <details>

Definición

<details> crea un elemento interactivo que permite ocultar o mostrar información adicional.

¿Para qué sirve?

Se utiliza para crear secciones desplegables sin necesidad de utilizar JavaScript.

Ejemplo

¿Qué es HTML?

HTML significa HyperText Markup Language. Es un lenguaje de marcado utilizado para estructurar el contenido de las páginas web.

Resultado

Aparecerá una sección que el usuario puede abrir y cerrar haciendo clic en el título.

20. <dialog>

Definición

<dialog> representa una ventana o cuadro de diálogo dentro de una página web.

¿Para qué sirve?

Se utiliza para mostrar información, mensajes, formularios u otros contenidos en forma de diálogo.

Ejemplo

Este es un cuadro de diálogo creado utilizando únicamente HTML.

Resultado

Se mostrará un cuadro de diálogo abierto dentro de la página.

21. <header>

Definición

<header> representa la cabecera de una página o de una sección.

¿Para qué sirve?

Se utiliza para colocar títulos, logotipos, menús u otra información introductoria.

Ejemplo

Mi página web

Esta es la cabecera de una sección.

Resultado

Se mostrará una sección identificada semánticamente como cabecera.

22. <mark>

Definición

<mark> representa texto que se desea resaltar por su importancia o relevancia.

¿Para qué sirve?

Sirve para destacar palabras o fragmentos importantes dentro de un texto.

Ejemplo

Esta palabra está resaltada.

Resultado

El texto marcado aparecerá resaltado visualmente.

23. <summary>

Definición

<summary> define el título visible de un elemento <details>.

¿Para qué sirve?

Permite indicar al usuario qué información aparecerá cuando se abra la sección desplegable.

Ejemplo

Información sobre HTML

HTML se utiliza para estructurar páginas web.

Resultado

El texto de summary funciona como el título que permite abrir o cerrar la información.

24. <map>

Definición

<map> permite crear un mapa de imagen con diferentes zonas interactivas.

¿Para qué sirve?

Permite hacer diferentes partes de una imagen seleccionables mediante la etiqueta <area>.

Ejemplo

Resultado

Una zona de la imagen puede funcionar como un enlace.

25. <figcaption>

Definición

<figcaption> representa el título o descripción de una figura.

¿Para qué sirve?

Se utiliza normalmente dentro de <figure> para describir una imagen, gráfico, código u otro contenido.

Ejemplo

Resultado

La descripción aparece asociada a la figura.

26. <aside>

Definición

<aside> representa contenido relacionado indirectamente con el contenido principal.

¿Para qué sirve?

Se puede utilizar para mostrar información complementaria, notas, enlaces relacionados u otro contenido secundario.

Ejemplo

Información adicional

Este contenido proporciona información complementaria al tema principal.

Resultado

Se muestra un bloque de contenido complementario.

27. <dialog>

Definición

<dialog> representa una ventana o cuadro de diálogo dentro de una página web.

¿Para qué sirve?

Se utiliza para mostrar mensajes, información, formularios u otros contenidos en forma de diálogo.

Ejemplo

Este es un mensaje dentro de un cuadro de diálogo.

Resultado

Se mostrará un cuadro de diálogo abierto dentro de la página.

28. <section>

Definición

<section> representa una sección independiente y temática de un documento.

¿Para qué sirve?

Sirve para dividir una página en diferentes secciones relacionadas con un tema específico.

Ejemplo

Sección de HTML

Esta sección contiene información relacionada con el lenguaje HTML.

Resultado

El contenido queda agrupado semánticamente dentro de una sección independiente.
